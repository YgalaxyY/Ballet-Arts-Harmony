## О проекте

Статический лендинг о балете с адаптивной сеткой, каруселью и эффектами прокрутки. Учебная адаптация шаблона [Free-Template.co](https://free-template.co/), указанного в HTML.

Для просмотра запустите локальный статический сервер и откройте [index.html](index.html). Стили, шрифты, изображения и сценарии хранятся рядом со страницей.

**Стек** · HTML, CSS, Bootstrap, jQuery, Owl Carousel. [English](README.en.md).
